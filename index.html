REQUISITO 01 // DETECCIÓN DE CARACTERÍSTICAS

Regla @supports (Base + Mejora)

Define primero un panel opaco de alto contraste (rgba(11, 17, 32, 0.95)) 100% legible. Si el navegador soporta desenfoque de fondo o mezcla color-mix(in oklch, ...), activa el cristal traslúcido. 

/* Base funcional segura */
.q4-quantum-dashboard {
  background-color: #0b1120;
  background-color: rgba(11, 17, 32, 0.95);
}
/* Mejora progresiva */
@supports ((-webkit-backdrop-filter: blur(22px))
           or (backdrop-filter: blur(22px))) {
  .q4-quantum-dashboard {
    background-color: rgba(11, 17, 32, 0.56);
    -webkit-backdrop-filter: blur(24px);
    backdrop-filter: blur(24px);
  }
}
REQUISITO 02 // RESERVAS Y PREFIJOS

Fallbacks y Prefijos con Estándar al Final

Implementa colores de reserva antes de gradientes de texto o oklch(), y prefijos -webkit- / -moz- seguidos siempre por la propiedad estándar al final.

[OK] color: #38bdf8; (Fallback sólido legible)
[OK] -webkit-background-clip: text;
[OK] background-clip: text; (Estándar al final)
[OK] -webkit-mask-image: linear-gradient(...);
[OK] mask-image: linear-gradient(...); (Estándar final)
REQUISITO 03 // ACCESIBILIDAD VESTIBULAR

@media (prefers-reduced-motion: reduce)

Respeta la preferencia de reducción de movimiento del sistema operativo deteniendo los bucles @keyframes y reduciendo transition-duration a 0.01ms sin perder claridad ni foco. 

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
